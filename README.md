# ORBIT — магазин кроссовок

Проект по практическим работам 3, 4, 10, 11 и 12. Тема, название, модели и SVG-иллюстрации придуманы для учебного сайта. Интерфейс на русском: HTML, CSS, локальный Bootstrap 5.3.3, обычный JavaScript. Сервер: Python Flask, база SQLite.

## Быстрый запуск

1. Установите Python 3.10 или новее.
2. Распакуйте архив и откройте папку `orbit`.
3. В Windows запустите `start.bat`. При первом запуске требуется интернет для установки библиотек.
4. Откройте http://127.0.0.1:5000. Для остановки сервера нажмите Ctrl+C.

Ручной запуск в терминале из папки проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

В Linux/macOS используйте `python3` и `.venv/bin/python` вместо пути Windows.

Файлы в `templates` — HTML-шаблоны Flask: их не нужно открывать двойным щелчком. Статическую демонстрацию можно открыть отдельно: `docs/index.html`.

## Что работает сразу

- Шесть страниц, понятные адреса, навигация и мобильное меню.
- Каталог, поиск, фильтр, сортировка каждого столбца в обе стороны.
- Скачивание настоящего Excel `.xlsx` и PDF с кириллицей. Выгружается текущий фильтр и порядок строк.
- Регистрация и вход через собственный Flask API. Пароли хранятся в виде хешей Werkzeug; cookie HttpOnly, защита POST-запросов CSRF.
- Общий чат: сообщения сохраняются в SQLite и обновляются раз в 3 секунды. Для отправки нужен вход. Проверьте двумя разными браузерами.
- Генерация QR-кода, 3D-витрина, вращающийся слайдер, карточки с переворотом, интерактивная банковская карта.
- Анимированные чекбоксы и поиск. Есть управление клавиатурой и поддержка уменьшенного движения.

База автоматически создаётся в `instance/orbit.db`. Не публикуйте её: в ней пользовательские данные. Папка исключена из Git. Данные тестов и предпросмотра в архив не включены.

## Настройка почты и оплаты

Скопируйте `.env.example` в `.env`, заполните настройки и перезапустите сервер. `.env` исключён из Git.

| Настройка | Что указать |
|---|---|
| `SECRET_KEY` | Случайная длинная строка; можно получить командой `python -c "import secrets; print(secrets.token_hex(32))"` |
| `PUBLIC_URL` | Полный адрес Flask-сайта без завершающего `/`; используется для QR и canonical |
| `COOKIE_SECURE` | `0` для локального HTTP, `1` для размещения по HTTPS |
| `SMTP_HOST`, `SMTP_PORT` | Сервер почты и порт: 587 с STARTTLS или 465 с SSL |
| `SMTP_USER`, `SMTP_PASSWORD` | Логин и пароль приложения почтового сервиса |
| `MAIL_FROM` | Разрешённый вашим SMTP отправитель |
| `MAIL_TO` | Адрес, на который отправлять обратную связь |
| `CLOUDPAYMENTS_PUBLIC_ID` | Public ID тестового терминала из личного кабинета CloudPayments |

Без SMTP форма показывает, что почта не подключена, и не сообщает об успешной отправке. После настройки письмо отправляется через SMTP, а успешно отправленное обращение фиксируется в базе. При ошибке SMTP пользователь получает сообщение об ошибке.

Оплата: войдите в аккаунт, откройте `/checkout`, отметьте чекбокс и нажмите кнопку оплаты. Сервер формирует параметры услуги «Подбор кроссовок» за 500 ₽, после чего открывается официальный виджет CloudPayments. Используйте тестовый терминал. Без Public ID выводится сообщение о необходимости настройки. Внешняя оплата и фактическая доставка письма не проверялись, поскольку доступы не предоставлены.

3D-карта рядом — отдельная демонстрация на вымышленных данных. Она не отправляет и не сохраняет номер карты или CVC. Платёжные реквизиты принимает исключительно виджет провайдера. Сайт не помечает заказ оплаченным на основании клиентского callback: полноценный учёт заказов и проверка подписанных уведомлений провайдера в эту учебную форму не входят.

Для QR-кода с телефона адрес `127.0.0.1` не подходит: установите в `PUBLIC_URL` доступный телефону адрес размещённого Flask-сайта.

## Загрузка на GitHub и GitHub Pages

1. Создайте репозиторий в своём GitHub-аккаунте.
2. Загрузите содержимое папки `orbit`, включая `docs`. Не загружайте `.env`, `.venv`, `instance` и `__pycache__`.
3. В репозитории откройте Settings → Pages → Deploy from a branch.
4. Выберите ветку `main`, каталог `/docs` и сохраните.
5. После сборки GitHub покажет ссылку вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

`docs` — самостоятельный адаптивный лендинг с коллекцией, изометрией и 3D-слайдером. Он работает и при размещении в подпапке репозитория. **GitHub Pages не исполняет Python**: аккаунты, общий чат, экспорт, почта и платёжный API работают в полной Flask-версии. Для публичной работы этих функций разместите Flask на Python-хостинге с постоянным диском, HTTPS и WSGI-сервером. Встроенный `app.run` предназначен для локальной демонстрации. Перед использованием реальных покупателей понадобятся также ограничение частоты запросов, сброс паролей и серверное подтверждение платежей.

После изменения главной страницы можно обновить лендинг: `python build_pages.py`.

## Структура и проверки

- `app.py` — маршруты, SQLite, API, почта, экспорт и QR.
- `templates/index.html` — разметка шести страниц, `404.html` — страница ошибки.
- `static/style.css`, `static/app.js` — стили и поведение.
- `static/images` — собственные SVG-кроссовки; `static/vendor` — Bootstrap с лицензией в заголовке; `static/fonts` — Noto Sans и лицензия OFL.
- `docs` — готовый лендинг GitHub Pages.
- `tests.py` — четыре группы автоматических проверок (страницы, аккаунты/чат, экспорт/сортировка, валидация).

Запуск проверок: `python -m unittest tests -v`. Проверки пройдены. Дополнительно проверены синтаксис JavaScript, отображение главной на настольном экране и каталог на ширине 390 px, фильтр и переключение сортировки в браузере. SMTP и CloudPayments требуют ваших настроек и отдельной проверки.
