# ORBIT — магазин кроссовок

Проект по практическим работам 3, 4, 10, 11 и 12. Тема, название, модели и SVG-иллюстрации придуманы для учебного сайта. Интерфейс на русском: HTML, CSS, локальный Bootstrap 5.3.3, обычный JavaScript. Сервер: Python Flask, база SQLite.

## Быстрый запуск

1. Установите Python 3.10 или новее.
2. Распакуйте архив и откройте папку `orbit`.
3. В Windows запустите `start.bat`. При первом запуске требуется интернет для установки библиотек.
4. Откройте http://127.0.0.1:5000. Для остановки сервера нажмите Ctrl+C.

Ручной запуск в терминале из папки проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```
